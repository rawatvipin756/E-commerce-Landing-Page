# 🛒 E-Commerce Landing Page

A modern and responsive e-commerce landing page built using HTML and CSS. The project demonstrates responsive layouts, product cards, and modern UI design principles.

## 🚀 Features

- Responsive Navigation Bar
- Hero Section
- Featured Products
- Product Cards
- Why Choose Us Section
- Customer Testimonials
- Responsive Footer
- Hover Effects
- Smooth Transitions

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- CSS Transitions
